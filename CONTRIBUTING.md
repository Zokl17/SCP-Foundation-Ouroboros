# Сборка и изменения

Репозиторий содержит готовую устанавливаемую поставку мода и соответствующий исходный код. Сборка нужна только для изменения C#.

## Локальная сборка в Windows

Нужны установленная RimWorld и отдельный Harmony. Для 1.6 используется MSBuild из .NET Framework 4.x; для сборки 1.7 нужен PowerShell 7.6+ на .NET 10. Библиотеки игры используются как локальные ссылки и не распространяются с модом.

Из корня репозитория в PowerShell:

```powershell
.\Build.ps1 -RimWorldDir 'C:\Games\RimWorld' -StageOnly
```

Укажите свой путь к игре. Для 1.6 DLL появится в `Build/Assemblies`, для 1.7 — в `Build/1.7`. Скрипт выбирает вариант по установленной игре. Чтобы заменить поставляемую DLL после успешной сборки, закройте RimWorld и выполните:

```powershell
.\Install.ps1 -GameVersion '1.6' # либо '1.7'
```

При установленном в `RimWorld/Mods/Combat` Combat Extended скрипт также собирает необязательный адаптер. Если CE находится в другом месте, после сборки основной DLL адаптер можно собрать существующим проектом, указав реальные пути:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe" `
  '.\Source\ScpFoundation.CombatExtended\ScpFoundation.CombatExtended.csproj' `
  /t:Build `
  '/p:RimWorldDir=C:\Games\RimWorld' `
  '/p:CombatExtendedDir=C:\Games\RimWorld\Mods\CombatExtended'
```

Основную DLL нужно собрать первой. Репозиторий не содержит игровых библиотек.

## Проверка изменений

После сборки проверьте изменённую механику в игре и журнал ошибок. Для совместимости с CE отдельно запускайте игру с CE и без него. Сценарии внутренней проверки и временные инструменты рабочего прототипа не входят в эту релизную поставку; наличие успешной сборки не означает прохождение всех игровых сценариев.
